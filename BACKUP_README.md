# CloudWM Backup & Restore System

## Overview

CloudWM includes an automatic backup system that protects your existing configurations before making changes during installation.

## How It Works

### Automatic Backups
- **When**: Runs automatically before any configuration-changing operation
- **Where**: Backups are stored in `~/.config/cloudwm-backups/`
- **Format**: Compressed tar.gz archives with timestamps
- **Retention**: Keeps the last 5 backups automatically

### What Gets Backed Up
- Shell configurations (`.bashrc`, `.zshrc`)
- Desktop configurations (`.xinitrc`, `.Xresources`, `.xprofile`)
- Application configs (`.config/fish`, `.config/rofi`, `.config/picom`, etc.)
- Themes and icons (`.themes`, `.icons`)
- Fonts (`.local/share/fonts`)

## Usage

### Manual Backup
```bash
./scripts/backup-configs.sh
```

### Manual Restore
```bash
./scripts/restore-configs.sh
```

### During Setup
Backups are created automatically when you run:
- `./setup.sh` → "Run ALL"
- `./setup.sh` → "Install packages" 
- `./setup.sh` → "Setup shell"

## Backup Files

Backup files are named: `cloudwm-backup-YYYYMMDD_HHMMSS.tar.gz`

Each backup contains:
- All backed up configuration files
- `BACKUP_INFO.txt` with metadata and restore instructions

## Restore Process

1. Run the restore script: `./scripts/restore-configs.sh`
2. Select a backup from the list (or use fzf for interactive selection)
3. Review backup information
4. Confirm the restore
5. Restart your session to apply changes

## Safety Features

- **Non-destructive**: Never modifies original files
- **Confirmation**: Always asks before overwriting
- **Rollback**: Easy to revert if something goes wrong
- **Cleanup**: Automatically removes old backups (keeps 5 most recent)

## Troubleshooting

### Backup Fails
- Check disk space in `/tmp` and `~/.config/cloudwm-backups/`
- Ensure you have read permissions for your config files

### Restore Fails
- Verify the backup file exists and is not corrupted
- Check write permissions in your home directory
- Make sure you're not running as root (unless intended)

### No Backups Found
- Check if `~/.config/cloudwm-backups/` exists
- Verify backup files have `.tar.gz` extension
- Run a manual backup to create the first backup

## Integration

The backup system is integrated into:
- Main setup script (`setup.sh`)
- Package installation (`install-packages.sh`)
- Shell setup (`setup-shell.sh`)

This ensures your configurations are always protected before any changes are made.
